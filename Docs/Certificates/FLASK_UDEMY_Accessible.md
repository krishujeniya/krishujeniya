## Course Curriculum & Competencies Demonstrated

### 1. Python Programming Foundations
- Data structures (lists, dictionaries, tuples, sets), control flow, and list comprehensions.
- Object-Oriented Programming (classes, inheritance, polymorphism, encapsulation, dunder methods).
- Exception handling, context managers, modular architecture, and package management via pip/virtual environments.

### 2. Flask Web Framework Architecture
- WSGI request-response lifecycle, route handlers, view functions, and dynamic URL parameters.
- Jinja2 templating: template inheritance, macros, filters, and context processors.
- Request parsing, query string handling, form parsing, and JSON API payloads.

### 3. State Management & Database Integration
- Session management, cookie signing, secret key configuration, and CSRF protection.
- Relational database integration using SQLAlchemy ORM: schema modeling, migrations, queries, and foreign key relationships.
- Authentication workflows: password hashing (bcrypt/werkzeug), session authentication, and protected endpoints.

### 4. Deployment & Production Patterns
- Gunicorn / uWSGI application server integration behind Nginx reverse proxy.
- Environment variable isolation (`.env`), CORS configuration, logging, and error handling middleware.
